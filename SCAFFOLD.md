# SJGE

I would like to create a suite of tools for creating manager-like games. Each game will have seasons, leagues, and
teams.
The games don't support physics, gameplay is limited to the management of teams. It is intended to support motorsport,
baseball, and, later, american football. Please scaffold this as a monorepo

## Structure

- **`specs`** Contains design documents and planning documents.
    - **`specs`** System and module specifications.

- **`packages`** These are the packages in the monorepo
    - **`lib`** Contains tools and utilities like calculators, database abstractions, etc.
    - **`core`** This is the core engine that manages the core parts of the system such as economics, seasons, leagues,
      teams, and players.
    - **`ui`** This will contain the library to support the UI
- **`products`** This is where the games will be implemented.
    - **`baseball`** This is where the baseball game will be implemented.
    - **`mororsport`** This is where the motorsport game will be implemented.
- **`.agents/skills`** This is where the skills will be stored.
- **`.agents/plans`** System and module plans generated by agents.

## Technologies

- nodejs
- javascript
- redis for cachinng and out of process memeory
- mongo for persistent storage
- Express.js for web server
- Vue.js for ui
- gnu make
- sqllite for caching and tabular data

## AGENTS.md

Please create an AGENTS.md with the following guidance

- This is a mono-repo
- Store all skills in the .agents/skills directory
- Store all plans in the .agents/plans directory
- Prefer well-attested npm libraries over new code, Ask for approval for new npm dependencies.
- Distinguish between "human player" and "in game player" by referring to the human player as "The Manager" and in-game
  player as "player"
- prefer GNU `make` for shell scripting and builds
